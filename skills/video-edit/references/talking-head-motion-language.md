# 口播包装与 MG 动效语言

## 1. 开场钩子

适用：惊讶、反常识、结论先行、重大变化。

- 人物全屏或中近景，0.2-0.4 秒轻推近。
- 重点词分两拍出现：情绪词先入，核心产品/结论随后落下。
- 可使用短促撞字、标记笔或数字放大；不加大卡片。
- 音效：一次低音冲击 + 一次轻 pop 即可。

## 2. 概念解释

适用：模型能力、方法论、观点解释。

- 人物缩到侧下方动态小窗，主画面出现 1 个中心概念。
- 中心概念拆成 2-4 个节点，随关键词逐个生成并连接。
- 当前节点高亮，上一节点降级但保留关系。
- 结束时节点聚合为一句结论，再把视觉焦点交回人物。

## 3. 操作流程/录屏

适用：平台操作、参数选择、生成流程。

- 录屏占主画面，人物小窗保持动态。
- 操作区域使用稳定局部放大、光圈、指示线或短标签。
- 步骤进度使用细线、编号或路径，不使用巨大步骤框。
- 鼠标点击、下拉选择、生成完成分别对应 click、tick、confirm。

## 4. 视频效果展示

适用：模型生成结果、案例和成片。

- 让视频成为主画面并完整播放有效动作区间。
- 人物可暂时消失或缩为小窗；不能用静态封面代替。
- 可用极轻版本标签和进度，不在画面上堆解释文字。
- 素材结束前准备下一画面，最后一帧不长时间停留。

## 5. 左右对比

适用：版本、前后、不同模型、不同方法。

- 两路视频等高并同步播放，明确版本标签。
- 比较维度只保留 1-3 个，例如一致性、人物数量、镜头时长。
- 使用进度条或状态点动态变化，不使用大白框围住每个词。
- 需要听原片时，口播淡出，播放原音，结束后直接切回人物。

## 6. 数据和事实

适用：收益、成本、速度、比例、时间。

- 数字和单位一起出现，禁止只强调数字导致语义错误。
- 条形、折线、计数器或前后差值必须随口播增长。
- 来源以小型来源条或截图呈现，不做夸张新闻墙。
- 结论先在图表中完成，再以艺术重点词收束。

## 7. 多步骤/多素材

适用：输入多张图、多个角色、多场景生成。

- 多个素材从不同方向短距离进入，按顺序汇入模型节点。
- 输出视频从节点右侧或下方展开，形成清晰输入→处理→输出。
- 素材缩略图数量过多时使用队列/胶片带，不堆成方框墙。
- 入口和出口动作使用同一条路径，保持空间连续。

## 8. 观点结论与 CTA

适用：总结、号召评论、关注或交流。

- 回到人物全屏，信息元素减少。
- 前文对象收束成 2-3 个关键词或一句结论。
- CTA 在口播说出时才出现，并保留可读终帧。
- 结尾口播和字幕不得提前裁切。

## 转场选择

| 语义关系 | 推荐转场 | 时长 |
|---|---|---|
| 同一对象继续 | 共享对象移动/缩放 | 0.25-0.55s |
| 观点切换 | 直接切 + 短音效 | 0-0.18s |
| 流程推进 | 路径延伸/节点传递 | 0.25-0.50s |
| 证据出现 | 轻滑入 + 模糊转清晰 | 0.20-0.40s |
| 人物让位给素材 | 人物缩窗 + 素材展开 | 0.30-0.55s |
| 素材结束回人物 | 素材收缩/硬切 + 人物已就绪 | 0.10-0.35s |
| 版本对比 | 中线展开/双屏同步出现 | 0.30-0.50s |

## 禁止模式

- 所有画面都是相同圆角方框。
- 方框超出屏幕、遮住脸或压住字幕。
- 人物小窗是静态截图。
- 视频素材只显示第一帧或结束后长时间停住。
- 每句话都做缩放，导致人物抖动。
- 纯黑底、暗色 HUD、廉价霓虹、随机粒子和无意义扫描线。
- 先显示完整信息，再等待旁白。
- 转场先把旧画面清空，再等新画面出现。
