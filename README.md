# 最新口播剪辑 Skills、组件与音效

本仓库打包 Codex 口播剪辑所用的最新 Skill、可复用 Remotion 组件及音效素材库。

## 内容

- `skills/video-edit/`：通用视频剪辑 Skill 和相关参考。
- `skills/remotion-talking-head-production/`：Remotion 口播剪辑 Skill、组件库、音效库、脚本 Schema、模板和流程参考。

只收录当前有效文件；不含备份目录、备份副本、用户原片/SRT/截图或成片。

## 最近沉淀的布局要求

- 30 秒之后也持续进行包装，并混合多种组件表现形式，避免全片单调重复。
- 信息/解释组件位于人物左侧；用户提供的证明素材位于人物右侧。遵从每次项目中用户最新的明确布局指令。
- 组件与口播语义同步出现，不提前剧透；保证停留时间和顺序可读。
- 避免挡脸、挡字幕、互相重叠，以及突兀的大块黑底样式。

## 使用

将对应 Skill 目录复制到 `~/.codex/skills/`，按需导入组件源码和音效文件到 Remotion 项目，并遵守各 Skill 内的工作流与验收要求。
