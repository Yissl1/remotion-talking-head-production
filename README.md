# Remotion 口播包装 Skill 发布包

本目录包含最终确认版的 16:9 Remotion 口播包装 Skill、可复用组件库和不含用户视频素材的 Remotion 组件模板。

## 目录

- `SKILL.md`：三阶段门控工作流。
- `references/`：最终版风格、组件库、素材语义映射、脚本规范、渲染验收和状态门控。
- `assets/remotion-components/`：最终版可复用 Remotion 组件源码及说明。
- `assets/templates/`：素材需求、MG 设计说明、剪辑脚本和状态模板。
- `examples/remotion-components-template/`：最终风格组件的 Remotion 示例源码。

## 已沉淀规则

- 16:9 横屏、灰黑偏黑的平行交错背景；字幕只用白色，并按最终确认版排版。
- 背景艺术字可按主题替换；未指定时使用固定英文字样。背景字的白色发光与信息卡样式分开处理。
- 信息组件、素材、人物缩放框和 MG 动画必须登记时间范围、安全矩形和入场外扩范围；组件严禁重叠、挡脸或互相遮挡。
- 不同语义组切换前先清空旧组件，必要时保留 6–12 帧交接间隔；同一语义组的组件可以共同停留，并在下一组完整进入后再整体退出。
- 单张图片默认放人物右侧；多图使用叠放后向两侧铺开的入场方式，不同多图组不能重复同一入场动效。
- 真实操作演示才使用鼠标跟随、关键字放大追踪和停留；普通素材稳定播放，不持续抖动。
- 证据素材按 SRT 语义对齐并独占播放；素材结束后回到全屏人物口播，避免原素材音频重叠。
- 操作演示可放到背景板主体区域并放大到约 2/3 画面；非操作素材必须保证观众看清内容。
- 信息卡、图标、条形/柱形、艺术字和 MG 动画均要有合理的出入场动效，并搭配轻量转场/提示音效。
- 人物缩放框只在需要辅助讲解时出现，去除黑边，使用柔和带发光边缘；完整回到人物全屏后及时消失。

## 使用

1. 将本目录安装/复制到 Codex 的 skills 目录，并保持目录名为 `remotion-talking-head-production`。
2. 新建口播项目时先回答 Skill 的风格确认问题。
3. 第一步提供主口播视频、SRT、录屏/截图和 MG 参考描述；不需要 MG 时明确说“不需要 MG，下一步”。
4. 确认脚本后，再确认 30 秒预览；预览通过后才渲染全片。
5. 示例只包含组件源码和少量通用音效，不包含用户视频、SRT、截图、临时文件或成片；实际项目需将自己的素材放入 `public/` 并在脚本中登记。

## 示例模板

`examples/remotion-components-template/` 只保留最终风格组件：

- `production-components.tsx`：字幕、信息卡、艺术字、数据条、流程、证据画面、单图、多图铺开、操作演示等组件。
- `MouseZoomCut.tsx`、`MouseZoomTwoTargets.tsx`：鼠标跟随与双目标放大追踪组件示例。
- `public/sfx/`：轻量通用提示、点击、冲击、whoosh 等音效。

模板没有包含旧撕纸风格组件，也没有包含任何用户特定的时间线和本地素材。
