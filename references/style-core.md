# 风格核心

本文件是 `source-style-report.md` 与用户最终反馈的执行摘要。原报告是分析资料；本文件中的约束才是 Skill 执行规则。

## 视觉定位

- 科技资讯、产品发布会、赛博工作台、轻纪录片。
- 人物负责观点与信任；网页、软件、手机界面和演示素材负责证据；数据卡、流程 MG 与艺术字负责降低理解成本。
- 不是单纯复制蓝色科技感，而是执行“论点 → 视觉证据 → 解释 → 结论”的结构。

## 画面节奏

每 2–5 秒出现一次可感知变化，但变化可以是节点揭示、UI 放大、关键词切换、素材替换或轻量转场，不要求频繁切镜。硬切为主，轻推入、淡化、遮罩揭示和短促光泽转场为辅。

## 布局模式

1. **人物主画面**：人物全屏，组件在人物两侧安全区，不能挡脸、嘴、手部重点动作或字幕。
2. **人物 + 证据小屏**：人物仍全屏；左侧为无框艺术字/标题，右侧为可读素材小屏。左右可依人物位置镜像。
3. **证据台**：灰黑偏黑或灰黑渐变光泽背景（推荐 `#111315`）；大素材约占 2/3 屏；左下放同步人物圆形小窗；左上只保留短文字，不使用多余矩形外框。
4. **全屏素材**：仅在素材必须大面积阅读时使用，和其他模式交替，避免整片像 PPT。

## 字幕

- 底部安全区居中，通常 1–2 行；16:9 的 1080p 画布建议约 38–48px 粗体。
- 全片文字、关键词、边框和组件强调统一使用亮白 `#F7F8FA` 及其透明度层级，不再使用冷蓝、青色、紫色或其他彩色高亮。
- 轻阴影或短下划线即可，避免厚重大黑底和过宽胶囊框。
- 字幕只表达“说了什么”；信息组件表达“意味着什么”，不要重复整句。

## 信息组件

- 少量使用有框卡片；更多使用无框艺术字、短标题、数字、标签、连接关系和真实证据框。
- 一张卡片只表达一个判断。内部信息必须逐项跟随语音出现。
- 线条只在局部承担连接或强调，不跨越人物脸部，不从画面一端拉到另一端。
- 入场建议 8–18 帧，出场 6–14 帧；分层出现，不要整组突然弹出。

## 证据素材

- 清晰度和可读性优先。展示素材稳定停留，不持续抖动、呼吸缩放或漂移。
- 可在入场时做一次 0.985→1.0 的轻缩放，随后固定；出场只做轻位移/淡出。
- 录屏应连续播放，不冻结首帧；必要时只做一次有目的的局部放大或追踪。

## 黑色背景艺术字

- 使用纯黑或近黑背景，将主题短语排成多条横向平行文字带；相邻行左右错位，形成整齐但不呆板的交错节奏。
- 实心字与描边字逐行交替，并用透明度层级、轻微渐变光泽或短暂扫光增加质感。
- 文案必须来自当前项目的 `themePhrase`。当前项目可使用“死都要死在AI上”，但不能固定为其他主题的默认文案；排版风格沉淀，具体艺术字内容随主题变化。
- 默认不使用旋转、竖排、大小散点堆叠或随机角度。文字数量要铺出背景层次，但不能压过素材、字幕、左上标题或人物小窗。

## 边缘发光与数字动画

- 部分信息卡、证据框、数字卡和人物圆形小窗可以在入场时启用亮白边缘发光；发光应在 8–18 帧内建立，停留时减弱，出场时随组件淡出。
- 数据组件的数字使用 8–18 帧快速递增，从 0 或较小起始值平滑变化到目标值，最后停在精确数字；单位、标签和来源按口播同步揭示。

## 动画和音效

- 所有组件有入场、停留和出场；流程节点按语义顺序出现，连接线随节点绘制。
- 音效只服务于出现、点击、连接、完成和转场等真实动作。人声是绝对主轨。
- 禁止无限循环、随机运动、持续抖动、频繁 glitch、连续 beep 和过大 whoosh。

## 色彩

灰黑偏黑背景 `#111315`；主文字和组件强调统一为亮白 `#F7F8FA`；次级文字使用 `rgba(247,248,250,.72)` 等透明度层级。允许使用黑色阴影和白色光晕制造层次，不默认使用其他色相。


## 最新最终视觉基准（v6 平行背景版，优先级高于旧预设）

当用户未提供新的参考，或明确选择“按已经沉淀好的视频制作规则”时，默认复现 `preview-61s-v6-parallel-backdrop.mp4` 所确认的最终包装逻辑：

- 16:9 横屏，灰黑偏黑背景；背景艺术字采用多行横向平行、左右交错、实心与描边交替的排版，文案随主题变化。
- 左上固定使用 `FIELD NOTE / AI COMPANION`、`REPORT STYLE · 16:9 / 30FPS` 和短横线信息，不使用矩形外框、箭头或挡脸长线。
- 人物全屏时人物仍是主体；只在左右安全区放少量无框短标题/语义标签，避开脸、嘴、手和字幕。
- 展示证据时切换到“证据台”：证据素材约占画面 2/3，左上是短标题，左下为同步、静音的人物圆形小窗；普通组件不得与证据素材重叠。
- 录屏、网页或视频证据需要阅读时，采用独占式大画面并去除黑边，默认 `objectFit: cover`，通过 `objectPosition` 裁切；禁止用 `contain` 留出上下黑边。
- 证据素材入场后保持稳定，不做持续抖动、循环缩放或无意义漂移。仅操作演示允许一次有目的的放大/追踪和鼠标标记。
- 所有颜色强调统一为亮白层级；不默认使用 cyan、blue、lime、violet 等色相。层级只用透明度、黑色阴影、白色边缘光晕和描边区分。
- 组件、信息卡、MG 和字幕均需按 SRT 语义同步，分层入场、停留、出场；不得提前剧透结论、数字、产品名或步骤。
- 数字组件从较小值快速递增到目标值，并在目标数字停住；目标数字不得在动画开始前提前显示。

### 证据素材互斥层级

证据台或独占式素材展示期间，关闭会与素材区域重叠的 `ComparePanel`、`TechCard`、`ImageSpread`、普通卡片和装饰线。需要补充信息时只放左上短标题、左下人物圆窗和底部字幕；若素材必须全屏展示，则隐藏普通背景组件，仅保留统一视觉地板与字幕。

## 2026-08-22 纠偏：最终 v6 基准的发光边界与稳定性（最高优先级）

本节是对最终确认版本的纠偏，优先级高于任何旧版示例、旧 Skill 或撕纸风格。它描述的是“最终 v6 平行背景版”已经确认的实际成片规则，不是可选的问答建议。

### 发光必须分层

- 图1、图2的信息卡、短标签、普通组件、字幕和普通素材边框**默认不发光**；不得因为“统一亮白”而给它们加白色外发光。
- 只有证据台/灰黑背景板里的**实心白色背景艺术字**允许使用克制的白色发光；描边艺术字不发光，背景板本身不做白色闪烁。
- 人物圆形小窗、操作演示聚焦圈或少数证据框只能在脚本明确需要时使用很弱的边缘光；这不等同于信息卡发光。
- 普通组件用透明度、细描边、黑色阴影、字号和分层入场建立层级；禁止用厚重光晕代替排版。

### 背景艺术字

- 背景为灰黑偏黑色；艺术字采用多行横向平行、左右交错、实心与描边交替的排版。
- `themePhrase` 是项目级文案输入：本项目使用“死都要死在AI上”；其他项目若用户没有指定，则使用固定英文艺术字，不把本项目中文文案写死为全局默认。
- 艺术字具体内容可以随主题变化，但排版、字距、行距、交错关系和克制发光规则保持一致。

### 严格时间码与防闪屏

- 主口播视频从第 0 帧连续播放；场景切换不得重新挂载、重新 seek、循环或用当前帧重置人物口播轨。
- 所有字幕、素材、信息组件和 MG 只允许在对应 SRT 语义窗口内出现，不得提前剧透数字、产品名、结论或下一句信息。
- 背景切换使用稳定的 opacity 淡入淡出；禁止整块背景缩放、强白色扫屏、单帧白闪和高亮 glitch。
- 真实视频/录屏预加载并用 `cover` 去除黑边；普通素材入场后保持稳定，不做持续抖动、循环缩放或无意义漂移。
- 静态图片在语义窗口内稳定停留不属于编码卡帧；验收时必须区分“内容静止”与“渲染冻结”，并检查场景切点前后连续帧。

### 素材与组件互斥

- 证据素材占据右侧约 2/3 或独占式大画面时，关闭会进入素材区域的普通信息卡、装饰线、箭头和底部组件；只保留左上短标题、左下同步静音人物圆窗和底部同步字幕。
- 普通非操作素材只做稳定展示；只有真实操作演示才允许一次有目的的放大追踪、鼠标追踪和聚焦圈。
