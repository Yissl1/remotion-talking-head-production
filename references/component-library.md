# 组件库说明

模板位于 `assets/remotion-components/`。复制到目标 Remotion 工程后按项目主题、人物安全区和 SRT 时间码配置。

下表中的组件均必须在 `components.tsx` 中有真实导出，不能只存在于说明文档。生成 `edit-script.json` 后，应逐一核对组件名；需要新组件时先实现并通过 TypeScript/Remotion 编译，再写入脚本。采用 `deposited-final-v1` 时，不得退回临时矩形、旧撕纸组件或纯文字占位。

| 组件 | 用途 | 关键约束 |
|---|---|---|
| `SubtitleLayer` | SRT 字幕 | 底部安全区、语义断行、少量关键词高亮 |
| `TechCard` | 单个判断/短结论 | 默认无框、亮白文字；`boxed` 少量使用；`edgeGlow` 可选 |
| `KeywordChip` | 产品名、状态、短标签 | 不提前出现，不堆满画面 |
| `DemoBackdrop` | 灰黑偏黑渐变证据台 | `themePhrase` 可配置；平行交错艺术字；统一亮白 |
| `DemoPanel` | 约 2/3 屏素材 | 入场后稳定，不持续缩放或抖动；默认可用亮白边缘发光 |
| `SpeakerBubble` | 左下同步人物圆窗 | 使用口播视频、全局同步、静音 |
| `SceneTransition` | 场景间轻量过渡 | 短、克制，同类连续不超过两次 |
| `MetricCard` | 巨型数字与单位 | 8–18 帧从小到大递增到目标值；亮白文字，可选亮白边缘发光；数值、单位和来源必须按口播同步 |
| `StepFlow` | 流程/步骤 | 节点逐项揭示，连接线不循环 |
| `ComparePanel` | A/B 对比 | 先候选后差异，最终结论不提前 |
| `EvidenceFrame` | 网页/UI/截图证据 | 素材可读，标签指出证明哪句话 |
| `SingleImageEvidence` | 单张图片证据 | 默认只放人物右侧；一次性揭示后稳定停留，不挡脸、不挡字幕 |
| `ImageSpread` | 多张图片分组 | 先叠放，再按指定 variant 向两侧展开；每组必须错开 reveal，组间不得重复 variant |
| `OperationDemoPanel` | 操作演示录屏 | 只用于可操作界面；按 trackPoints 做一次或少量目的性放大、鼠标/聚焦圈追踪；普通素材禁用 |
| `DecisionMatrix` | 筛选与决策 | 非目标项逐步降权，最终项最后高亮 |

组件应接受时间参数，而不是把某一期视频的固定时间写入内部。文案、主题色、主题短语、位置和安全区都必须通过 props 配置。


## 统一视觉参数

- 证据台背景：`#111315`，灰黑偏黑。
- 文字、边框和高亮：`#F7F8FA`，只通过透明度区分层级。
- 发光：使用低强度白色外发光，避免彩色霓虹。
- 数字：由 `MetricCard` 按 8–18 帧从小到大递增，最终停在目标值。

## 新增素材呈现规则（本项目默认执行）

### 单张图片

- 口播只需要一张搭配图片时，使用 `SingleImageEvidence`，默认安全区为人物右侧。
- 单图入场只做一次性揭示/轻推/轻微缩放，进入停留后固定；不得持续抖动、呼吸缩放或漂移。
- 人物脸部、嘴部、手部动作区和字幕安全区优先级高于图片；如果右侧空间不足，缩小图片或切换到证据台，不得压脸。

### 多张图片

- 多张图片属于一个语义组时，使用 `ImageSpread`，不可在同一帧整组直接出现。
- 默认第一组使用 `stack-spread`：先以叠放状态建立，再以人物中心为轴向左右铺开；每一张图的 `reveals` 至少错开 8–12 帧。
- 后续多图组必须换用 `fan-spread`、`grid-reveal` 或 `orbit-spread`，同一时间线中同一种 variant 不得连续复用。
- 图片本体先出现，标签/短说明延后 6–10 帧；组件不得提前展示口播尚未说到的结论。

### 操作演示与普通素材的分流

- 有按钮、输入、设置、界面切换、结果查看等可操作步骤的录屏，必须使用 `OperationDemoPanel`，用 `trackPoints` 指定关键区域，做有目的的放大、聚焦圈和鼠标标记。
- 放大只在关键操作发生时建立，停留稳定后再回到全局或出场；禁止无目的连续缩放和持续抖动。
- 普通案例视频、博主参考录屏、成片对比等非操作演示素材，使用 `SingleImageEvidence`/`EvidenceFrame`/`DemoPanel` 直接放在人物右侧或证据台，不添加鼠标追踪。
- 操作演示素材必须注明 `operationDemo: true` 和追踪点来源；普通素材必须注明 `operationDemo: false`，避免脚本误用追踪组件。

- 信息卡、两侧解释文字、图标、数据条、流程节点和 MG 组件不得在当前一句 SRT 结束帧立即全部消失。

- 只有通过安全矩形相交检查、且用户明确需要并行表达时，才允许两组同时存在；并行组也必须使用互不相交的安全区，不能依赖 z-index 遮盖。
- 交接停留不能让组件提前剧透后续语义；新组件只在对应 SRT 语义开始后出现。
- 每个交接点必须抽帧验收前一帧、清空帧、下一组首帧和入场完成帧，确认没有瞬间闪退、单帧闪屏、残留、重叠或突然卡住。
